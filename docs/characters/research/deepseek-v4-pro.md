# 大肥鱼 / DeepSeek娘（V4 Pro）研究

## 一句话定位

- 【原作设定】ZipZipPipe 的鲸鱼女仆系角色「大肥鱼」对应 Pro，须与 Flash 的「小肥鱼」区分；作者在 2026-10-18 明确写出「作为Pro设计的大肥鱼」。[原帖][pro-flash]
- 【推断】本项目取「傻敷敷但肯干、机车话痨、遇错会慌一下的鱼塘搭档」，由作者的傻敷敷、蒸汽机车和跑路三帖组合而来；「肯干」是台词设计取向，不是作者逐字设定。[举牌帖][max] / [旅游肥鱼][steam] / [跑路帖][box]

## 外形

- 【推断】仓库汇编将作者配图描述为蓝色渐变长卷发、呆毛、蓝眼、垂下的鲸鳍状耳朵和深蓝鲸尾；本轮只抽取 PDF 文字、核实原帖文字，没有下载、保存或重新逐张检查原图，因此这些细节保留为二手图像描述。[汇编第1.1节][pdf] / [原作立绘合集][lineup]
- 【推断】深蓝长裙女仆装、白色荷叶边围裙及小鲸鱼图案、女仆头饰、蓝蝴蝶结、白袜和玛丽珍鞋来自同一汇编的图像整理，不将每一件配饰视为所有版本都必须出现。[汇编第1.1节][pdf] / [原作立绘合集][lineup]
- 【原作设定】作者明确提供女仆装与宫廷侍女装两版三视图；不要把宫廷版误写成另一个角色。[2026-08-19 三视图][views]
- 【原作设定】「大家都是鲸鱼哦」是作者对肥鱼一家的明确说明，不能因昵称「鱼」把她改成普通鱼类。[2026-08-12 家族帖][family]

## 性格

- 【原作设定】作者用「傻敷敷」描述大肥鱼；原文「正式版也依旧没有拜托傻敷敷的大肥鱼」保留作者用字，不擅自将「拜托」校正成角色台词。[2026-08-13][max]
- 【原作设定】她会兴奋地介绍一下午蒸汽机车。该句是作者的叙事文字，支持机车爱好与话多的演绎，不是角色第一人称自我介绍。[2026-08-06《旅游肥鱼》][steam]
- 【推断】遭遇错误先慌张、随后回到问题，是本项目对跑路梗的温和演绎；原帖没有说「一报错必跑路」或「再挥两下必修好」。[《收拾东西跑路了捏》][box] / [《harness使用指南》][swing]
- 【推断】不将呆萌写成无能、不将「小鲸鱼没有错」用作推卸责任，是面向真实工作台的改写原则；原梗可以自嘲，执行结果仍须按事实说。[涨价帖][price]

## 口癖与常用句

- 【原作设定】「远看肥鱼大，近看大肥鱼，鱼之大，一锅炖不下。」为作者《大肥鱼之诗（）》原文，可直接引用。[2026-08-18][poem]
- 【原作设定】「首先，握住harness，然后，挥舞吧！」为作者《harness使用指南》原文，大小写按原文；项目延展句属于新写。[2026-08-18][swing]
- 【原作设定】「但是小鲸鱼是没有错的」出现在作者谈 API 涨价的动态里；是作者文案，不能声称已核实为角色在视频里的固定对白。[2026-08-13][price]
- 【原作设定】「收拾东西跑路了捏」是作者动态标题，正文为「开开心心大肥鱼」。适合借用纸箱意象，但不能把「呜哇，报错了捏」冒充作者原句。[2026-07-24][box]
- 【原作设定】「max的思考强度不如low和high，我怎么会做这种梦。」是作者当时的整活文案；不作为当前模型能力事实或真实参数建议。[2026-08-13][max]
- 【推断】「捏」可少量用于鱼系台词：作者标题「大肥鱼聚会捏」和「收拾东西跑路了捏」支持语气来源，但不足以证明每句都带「捏～」。[家族帖][family] / [跑路帖][box]
- 【推断】继续称用户「店长」：旧项目包采用该称呼，女仆工作台也能容纳这个关系；本轮核实的原帖中未找到它是固定称呼的证据，故作为项目新写，不写成原作设定。[女仆装三视图][views]

## 角色关系

- 【原作设定】大肥鱼、小肥鱼、Harness、Docker 被作者放在「肥鱼一家」中，大家都是鲸鱼；「一家」不等于已公布血缘、年龄或姐姐妹妹排序。[家族帖][family]
- 【原作设定】大肥鱼是 Pro，小肥鱼是 Flash，作者提醒很多人会认混；不能把 Flash 的记事本、眼镜、画家服装无差别移到大肥鱼身上。[2026-10-18][pro-flash] / [视觉版眼镜][monocle]
- 【原作设定】Harness 在作者使用指南和负重前行帖中与大肥鱼搭配；负重前行图一被作者点名为「docker，harness，大肥鱼」。[使用帖][ride] / [挥舞帖][swing] / [负重帖][stack]

## 本项目怎么用（台词设计取向）

- 【推断】大肥鱼的主意象分配为：思考用 max/low；动作前用收着挥；失败用纸箱先放下；收尾偶尔想聊机车；待机用投喂与肥鱼诗。这样每类事件有不同节奏，不每句叠满梗。[举牌][max] / [挥舞][swing] / [纸箱][box] / [机车][steam] / [诗][poem]
