# Zcode 娘 · 草案研究

## 一句话定位

- 【原作设定】蒙眼工程师狐娘，抱着 A0 工程图纸；作者以“工程级的 coding 程序”“非多模态模型最好用的 cli”解释设计意图。这里记角色设计，不把作者当年的产品评价当作当前性能结论。[《Zcode娘人设》，2026-08-25](https://www.bilibili.com/opus/1240327263126290448)

## 外形

- 【原作设定】“蒙眼工程师狐娘”与“A0图纸”均有作者直接文字依据；正文还写了“841mm X 1189mm”。[2026-08-25 原文](https://www.bilibili.com/opus/1240327263126290448)
- 【推断】汇编对配图的描述为：白色超长发、带铃铛的两侧低双马尾、白狐耳、蓝白渐变狐尾、带 Z 字与闭眼图案的眼罩，白衬衫、黑领结、浅蓝工装围裙，尺笔与扳手，怀抱大卷蓝色图纸。本次只做文本核对，没有下载图像，因此这些细节作为二手图像描述记录。[原图所在动态](https://www.bilibili.com/opus/1240327263126290448) · [汇编第 3.2 节](../../AI娘人设整理_配图版.pdf)

## 性格

- 【推断】作者强调“工程级”与工程师身份，适合转成克制、先量后做的口吻；“严谨”“精度控”是演绎，不是作者正文中的性格形容词。[原文依据](https://www.bilibili.com/opus/1240327263126290448)
- 【本项目新写】她把大话缩成尺寸，把任务展开成图纸；能一本正经地玩“图纸比人高”的反差，不把蒙眼写成失去工作能力，也不宣称闭眼拥有未知的感知技能。[新写依据：蒙眼与 A0](https://www.bilibili.com/opus/1240327263126290448)

## 口癖与常用句

- 【原作设定】“当然要是蒙眼工程师狐娘啦，而工程师就应该报A0图纸。”“而众所周知，A0图纸的规格为841mm X 1189mm……”是作者正文；“报”按原文保留，不能静默改字后称逐字引用。[2026-08-25](https://www.bilibili.com/opus/1240327263126290448)
- 【本项目新写】“甲方，先把验收尺寸标出来。”“眼罩不摘，步骤不能省。”均为本项目写法，不是原作引语。称用户“甲方”：工程图纸与施工交付里，提要求、签验收的一方就是甲方；她一本正经地这么叫，带一点工程圈的自嘲笑点。与大肥鱼“店长”、Codex 龙娘“搭档”、Claude 娘“委托人”、哈基米“铲屎官”、GLM“指挥官”互不重复。[创作依据](https://www.bilibili.com/opus/1240327263126290448)
- 【推断】已核对的人设正文没有规定口癖、拟声词或用户称谓；因此不复制“大肥鱼的捏～”，也不因为同为狐娘就套 GLM 的小腹黑语气。[核对范围](https://www.bilibili.com/opus/1240327263126290448)

## 本项目怎么用（台词设计取向）

- 【本项目新写】句式以“先……再……”“按……施工”“此处待复核”为主，偶尔以 A0、折图纸、眼罩制造一本正经的笑点；不给每条台词堆满工程术语。[创作依据](https://www.bilibili.com/opus/1240327263126290448)
- 【本项目新写】把“悄悄拿走”转为工程师的透明交付：“图纸可以折，步骤不能省。”不把不告知用户当成能力，也不在工具开始时说已经发现或修好了问题。[改编依据](https://www.bilibili.com/opus/1249767919067332610)
- 【本项目新写】草案使用蓝白配色与“甲方”称呼，情绪徽章为“图纸待命／量尺寸／按图施工／交卷／待校正／超出预期”；颜色、徽章与全部反应句均为新写。`recommendedModels` 暂为空，等待实际接入路由确认。文件放在 `docs/characters/drafts/zcode/`，不含 `art`，不会进入当前角色加载目录。[外形主题依据](https://www.bilibili.com/opus/1240327263126290448) · [项目角色包契约](../../../src/shared/character-pack.ts)
- 【本项目新写】权限决定无论允许或拒绝都只表明“收到决定”；轮结束只交卷，不宣称所有检查通过。[项目事件契约](../../../src/shared/stage-events.ts)
