## 外形

- 【推断】亮蓝长发、鲸耳鲸尾、战术或工装风、护甲、腰包、靴子来自 PDF 对家族与负重图的二手说明，本轮未重新查看原图或下载图片。[汇编第1.4节][pdf] / [家族原帖][family] / [负重原帖][stack]
- 【原作设定】作者明确说肥鱼一家「大家都是鲸鱼哦」，不能把 Docker 简化成普通货箱或软件图标。[家族帖][family]

## 性格

- 【推断】原帖文字不足以确定 Docker 的语速、脾气、年龄或口癖；「可靠、能扛事」只能作为基于负重构图的可选项目演绎，不能标成作者正设。[负重帖][stack]

## 口癖与常用句

- 【原作设定】「可是正统的蓝色大肥鱼」是作者介绍 Docker 的句子，不是已经核实的 Docker 自我介绍。[家族帖][family]
- 【推断】尚无足够的一手角色对白建立常用句，本次不为 Docker 创建上线台词包；若以后写「底下我撑着，先把上面的事说清」，需标为项目新写且不能暗示环境或容器已经启动。[负重帖][stack]

## 名场面与梗

- 【原作设定】《负重前行的小可爱们》正文写「图一为docker，harness，大肥鱼」。[2026-08-16][stack]
- 【推断】Docker 最下、Harness 中间、大肥鱼最上的具体位置是汇编图像整理；可以做家族协作的演出意象，不能据此断言她最年长或最强。[汇编第1.4节][pdf] / [负重帖][stack]

## 角色关系

- 【原作设定】Docker 与大肥鱼、小肥鱼、Harness 同在「肥鱼一家」。[家族帖][family]
- 【推断】「一家」是作者群像命名，未核实到四者的血缘、辈分和上下级；与 Harness 的软件层关系不应自动写成角色主仆。[家族帖][family] / [负重帖][stack]
- 【推断】未核实 Docker 与 GPT/Codex 龙娘、Gemini 哈基米、Claude、GLM、Zcode 的专属互动；后续不能用软件生态的关系代替人物剧情。[作者动态入口][space]

## 本项目怎么用（台词设计取向）

- 【推断】本轮只保留家族资料与后续方向，不创建 Docker JSON；若以后扩展，以稳当工装伙伴为候选取向，但须与 Harness 的包容接应区分。[家族帖][family] / [Harness初稿](https://www.bilibili.com/opus/1235342292138590229)
- 【推断】Docker 角色不能凭名称宣称容器、镜像或项目环境已经准备完成；所有舞台台词须以事件证据为准。[项目事件契约](../../../src/shared/stage-events.ts)
