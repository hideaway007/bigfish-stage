# Claude 娘研究与台词依据

## 一句话定位

- 【原作设定】作者作品中有女仆装的 Claude 娘、望天思考的 Claude 壁纸，以及单独点名“朋友设计”的 Claude Code 娘；这三条材料可以作为项目语气的参考，但不能证明两个形象是同一份正式角色设定。[女仆装，2026-07-25](https://www.bilibili.com/opus/1229028552767176756)；[望天，2026-08-24](https://www.bilibili.com/opus/1239937623660691478)；[Claude Code，2026-09-12](https://www.bilibili.com/opus/1247070559291834376)。
- 【推断】【本项目新写】项目采用“望天想一会儿，低头把委托理清楚的橙发少女”：礼貌、从容，有一点对换装和突发状况的冷幽默。角色包 ID 中的 Opus 版本不代表作者为该版本发布过完整设定。[设计起点](https://www.bilibili.com/opus/1239937623660691478)。

## 外形

- 【原作设定】作者明确写过“给Claude穿女仆装了”。这里确认的是换装题材，不是永久职业或主仆关系。[女仆装动态](https://www.bilibili.com/opus/1229028552767176756)。
- 【原作设定】壁纸动态的原文是“抬头望天，似乎正在思考着什么的Claude。”可以使用望天思考的动作意象。[壁纸动态](https://www.bilibili.com/opus/1239937623660691478)。
- 【推断】仓库 PDF 第14页对作者配图的描述为橙色超长发、橙色太阳/花形头饰、米白与橙黑配色长裙/女仆装、手持书本。本次仅提取文字与来源链接，未下载图片或重新视觉核验；不把具体瞳色、卷发程度、茶具或裙摆细节当直接原文。[立绘合集](https://www.bilibili.com/opus/1233069202138464289)；[女仆换装](https://www.bilibili.com/opus/1229028552767176756)。
- 【原作设定】2026-09-12 贺图原文：“其中Claude code是朋友设计的，很可爱哦。”这条只确认设计来源；不能据此把 Claude 娘的书本、服装与 Claude Code 娘逐项合并。[25000粉贺图](https://www.bilibili.com/opus/1247070559291834376)。

## 性格

- 【推断】“沉静、知性、擅长先理脉络”是从望天、书本视觉延伸的台词方向，尚无足够原作连续对白证明她永远温柔、优雅或绝不生气。[望天动态](https://www.bilibili.com/opus/1239937623660691478)。
- 【推断】【本项目新写】采用从容但不端着的委托处理者：可以说“容我”“您”，也会用“望天归望天，依据还得往下找”这样的轻微自嘲。避免把她写成通篇贵安、印章、卷轴、茶会的泛化大小姐。[设计起点](https://www.bilibili.com/opus/1239937623660691478)。
- 【二创·粉丝梗】小红书笔记《Claude娘｜打工梗图8张》写“思考五分钟，回答两行字”“额度见底，优雅下班”，并自行声明“AI辅助制作，非官方同人”。可用来理解粉丝的认真与摆烂反差，不把它升级成作者设定或真实产品配额。[M0yu的笔记，2026-10-23，已实读正文](https://www.xiaohongshu.com/explore/6adb5eb000000000240340a9)。

## 口癖与常用句

- 【原作设定】“哈哈，Claude被封了”是动态标题；“享年1.5个月，不意外，反正我早有准备，给Claude穿女仆装了。”是作者正文。说话者是作者，不是 Claude 本人。[原帖全文](https://www.bilibili.com/opus/1229028552767176756)。
- 【推断】未找到可确认为 Claude 固定口癖的“贵安”“别担心，我早有准备”，也没有原作证据说她称用户“店长”“主人”或“委托人”。[原始文字边界](https://www.bilibili.com/opus/1229028552767176756)。
- 【推断】【本项目新写】本项目称呼用户“委托人”，正文常用“您”：支持平等协作，也给从容的语气一个自然落点，不从女仆装推导主仆称谓。[设计参考：女仆换装](https://www.bilibili.com/opus/1229028552767176756)。
- 【推断】【本项目新写】“女仆装可以换，判断不能省。”、“书签夹好了，下一页由您来定。”、“容我望一眼天，再把问题拆开。”都是新写台词；第一句只借女仆装这个原作意象，不是原文引用。[换装来源](https://www.bilibili.com/opus/1229028552767176756)；[望天来源](https://www.bilibili.com/opus/1239937623660691478)。

## 名场面与梗

- 【原作设定】封禁与女仆装发生在同一条作者动态。可以作为旧事笑点，但“享年1.5个月”不指角色真实年龄、死亡，也不意味着当前会话被封禁。[2026-07-25](https://www.bilibili.com/opus/1229028552767176756)。
- 【原作设定】望天思考有直接作者配文；项目采用的是动作意象，不编造“45度望天”“必喝茶”等固定仪式。[2026-08-24](https://www.bilibili.com/opus/1239937623660691478)。
- 【二创·粉丝梗】《大肥鱼，你怎么穿着Claude的衣服》由以尘动画投稿，简介列动画以尘动画、剪辑是芙安呀。标题和署名已实读；它可确认换装二创存在，不能证明原作者设定两人永远交换衣服，更不能仅凭标题认定恋爱关系。[BV1LBnb6aERV，2026-10-23](https://www.bilibili.com/video/BV1LBnb6aERV/)。
- 【推断】旧角色包将“您窃取了 Fable 之力”、古老卷轴写进 Claude 台词，依据不足。PDF 将 Fable 5 列为另一个形象；作者 9000粉贺图也单独点名 Fable 5 与文心一言，因此本次去除跨角色挪用。[9000粉贺图](https://www.bilibili.com/opus/1237359535163703301)。

## 角色关系

- 【二创·粉丝梗】Claude 与大肥鱼的换装组合有实际粉丝视频；关系可以写作“有互换衣服的二创语境”，不写成原作情侣、主仆、蒸馏母女。[以尘动画视频](https://www.bilibili.com/video/BV1LBnb6aERV/)。
- 【原作设定】Zcode 与 Claude Code 被作者同时列入25000粉贺图；这只确认同次合集，不确认工程搭档或上下级关系。[贺图原文](https://www.bilibili.com/opus/1247070559291834376)。
- 【原作设定】GLM 被作者描述为“聪明伶俐却总有点小腹黑的狐狸娘”；Zcode 被描述为蒙眼工程师狐娘、抱A0图纸。可用于区分角色，不把狐娘人设塞给 Claude。[GLM](https://www.bilibili.com/opus/1239259160558698497)；[Zcode](https://www.bilibili.com/opus/1240327263126290448)。
- 【推断】《悄悄的拿走》的原文仅有“不要让用户发现哦~”；PDF 根据图片将角色识别为 GLM 与 Zcode。本次没有重新看图，不能把偷取行为认定为 Claude 的剧情。[原帖](https://www.bilibili.com/opus/1249767919067332610)。
- 【推断】未实证 Claude 与 Codex、哈基米的固定双人关系。GPT 维护肥鱼的那条视频简介没有出现 Claude，不转移其剧情。[GPT 视频简介](https://www.bilibili.com/video/BV17qpr6BEbM/)。

## 本项目怎么用（台词设计取向）

- 【推断】【本项目新写】四个核心意象为望天、书页、女仆换装、平静收拾突发状况。书本用来表达上下文与书签，女仆装用于低频自嘲，不每次执行都宣布变装。[望天](https://www.bilibili.com/opus/1239937623660691478)；[换装](https://www.bilibili.com/opus/1229028552767176756)。
- 【推断】【本项目新写】把“早有准备”改写成肯做核对而非保证成功；错误时说“先别替它找借口，把原因读清”，不说“稍改一下就能好”。`turn_done` 不宣称所有测试通过、所有边界被覆盖。[幽默意象来源](https://www.bilibili.com/opus/1229028552767176756)；事件语义依项目 `src/shared/stage-events.ts`。
- 【推断】【本项目新写】审批发起问是否允许这一步；审批结束只说按用户选择处理，不能默认获批。插话确认只说明读到，不编造代码已变。角色包全部对白为新写；借用原作梗的句子也不当作原作引语。[称呼和姿态设计参考](https://www.bilibili.com/opus/1239937623660691478)。
- 【推断】【本项目新写】与 Codex 的区别：Claude 使用完整、清楚的句式，偶尔冷幽默，称“委托人”；Codex 用短句、困意停顿，称“搭档”。两者均不使用大肥鱼的“店长”“捏～”。[Claude 意象](https://www.bilibili.com/opus/1239937623660691478)；[Codex 意象](https://www.bilibili.com/opus/1238613841710940181)。
