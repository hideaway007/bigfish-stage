# 小肥鱼 / DeepSeek V4 Flash（V4F）研究

## 一句话定位

- 【原作设定】小肥鱼对应 Flash，与「作为Pro设计的大肥鱼」不是同一角色；作者明确说很多人会认混。[2026-10-18《DeepSeek V4.1 Flash》][identity]
- 【推断】本项目用「记事本里的轻巧小鲸鱼」与大肥鱼的机车话痨区分；这是一种基于道具的台词设计，不是已公布的性格称号。[汇编第1.2节][pdf] / [作者角色合集][lineup]

## 外形

- 【推断】蓝发、鲸耳鲸尾、侧麻花辫、女仆装、围裙口袋里的笔、手中记事本与笔，为 PDF 对作者图的二手描述；本轮未重新检查原图，不把这些细节当本轮一手视觉核验结果。[汇编第1.2节][pdf] / [08-15角色合集][lineup] / [08-19三视图][views]
- 【原作设定】作者为 V4F 视觉模型更新形象，明确「增加一副单片眼镜作为其视觉能力象征，以最小程度修改」。这是角色版本线索，不保证当前执行模型有视觉能力。[2026-08-21][monocle]
- 【原作设定】10-18 作者为她尝试画家风格服装，说衣服由小肥鱼设计，并表达「或许某天，我们的小肥鱼真的能画出她想象的画作吧」。[原帖][identity]
- 【推断】贝雷帽、圆框眼镜、画笔、格纹短裙和长外套是 PDF 对 10-18 配图的描述；画家版、单片眼镜版和早期女仆版不应不加区分地拼成唯一标准服装。[汇编第1.2节][pdf] / [画家版原帖][identity]

## 性格

- 【推断】本轮作者文字尚不足以确认「害羞」「急性子」「天才画家」等固定性格；草案采用轻巧、条理清楚、有一点想画画的愿望，明确属于项目演绎。[画家版原帖][identity]
- 【推断】让她温和提醒别人别认错鱼，来源是作者说两只鱼容易被混淆；不把大肥鱼的呆萌、蒸汽机车爱好、挥舞 Harness 全套移植过来。[身份区分帖][identity]

## 口癖与常用句

- 【原作设定】「小肥鱼可爱捏」是作者 07-31 文案，「小肥鱼（V4F）」是 08-15 作者明确点名；这些是作者说她，不是她说自己的口头禅。[07-31][early] / [08-15][lineup]
- 【推断】「是小肥鱼哦，别把两只鱼认反啦」「先记下来，再一项一项看」均为项目新写；目前没有查到足够证据支持稳定的角色原话口癖。[身份区分帖][identity] / [造型的二手说明][pdf]
- 【推断】沿用「店长」以维持项目称呼一致；不是本轮查实的作者固定称谓。[作者动态入口][space]

## 名场面与梗

- 【原作设定】作者在 V4F 先发布时写「没想到没想到，竟然是V4F先发了」；可做「先到的小鲸鱼」意象，不把当时发布顺序写成现在的性能承诺。[2026-07-31][early]
- 【原作设定】单片眼镜是视觉能力形象更新、画家风格是后来的服装尝试，两者有各自明确原帖。[眼镜][monocle] / [画家服装][identity]
- 【推断】「我不是大肥鱼……」出现在 PDF 对鲸鱼表情包专栏封面的说明，未找到对应的一手完整台词；草案只采用认错鱼的情境，不将这句列为原作引语。[汇编第1.2节][pdf]

## 角色关系

- 【原作设定】她与大肥鱼、Harness、Docker 同属作者「肥鱼一家」，「大家都是鲸鱼哦」。[2026-08-12][family]
- 【推断】没有由「小」推导出年龄、妹妹身份或血缘；与 Pro 的区别以作者明说的模型对应为准。[家族帖][family] / [身份帖][identity]
- 【推断】本轮未核实她与 GPT/Codex 龙娘、Gemini 哈基米、Claude、GLM、Zcode 的特定互动或稳定亲疏关系；草案不借用大肥鱼与 GPT 视频里的关系作为她的经历。[作者角色合集][lineup] / [作者大肥鱼视频](https://www.bilibili.com/video/BV17qpr6BEbM/)

## 本项目怎么用（台词设计取向）

- 【推断】草案位于 `docs/characters/drafts/deepseek-v4-flash/character.json`，不含 `art`，不进入应用公开角色目录；台词用「记、圈、草稿、落笔」组织，不用外形替真实视觉工具作保证。[眼镜原帖][monocle] / [项目角色契约](../../../src/shared/character-pack.ts)
- 【推断】全部草案反应、情绪标签、UI 文案为新写；`turn_done` 只表达本轮答复收束，不说清单全勾、测试已过或问题已修好。[项目事件契约](../../../src/shared/stage-events.ts)
- 【推断】小肥鱼具体授权范围不能仅凭「同一家」自动认定；需在公开采用形象前核对角色链路与作者声明。已核实的大肥鱼声明为 CC BY-NC-SA 4.0，作者视频另说明鲸鱼娘上善无形→ZipZipPipe 二创链。[大肥鱼声明][license] / [作者视频声明](https://www.bilibili.com/video/BV17qpr6BEbM/)
