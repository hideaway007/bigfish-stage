# Codex 龙娘研究与台词依据

## 一句话定位

- 【原作设定】Codex 是作者点名的龙娘之一；作者明确说明“Codex娘的形象来源于群友”。这确认了角色身份和设计来源，不能把全部设计独占归于 ZipZipPipe。[龙娘合集，2026-08-15](https://www.bilibili.com/opus/1236581050888486921)；[龙娘三视图，2026-08-20](https://www.bilibili.com/opus/1238613841710940181)。
- 【推断】【本项目新写】项目将她写成“捧着终端便签、慢半拍但认真核对的小龙搭档”。这是从视觉延伸的表演方向，尚无足够原作对白支持固定性格。[视觉依据：三视图](https://www.bilibili.com/opus/1238613841710940181)。

## 外形

- 【原作设定】三视图明确列出 GPT娘、Image 2娘、Codex娘，并注明 Codex 来自群友；本次通过浏览器实读了原帖文字。[原帖](https://www.bilibili.com/opus/1238613841710940181)。
- 【推断】仓库 PDF 第9—10页对配图的描述为：小个子白色龙娘、淡蓝白长卷发、小龙角、闭眼困倦状、宽松白色睡衣式连衣裙、毛绒拖鞋、手持写着 `>_` 的便签。这是二手图像描述；本次只读取文字与链接，没有下载图片，也没有重新视觉核验颜色或衣料。[所述原图来源](https://www.bilibili.com/opus/1238613841710940181)；[合集来源](https://www.bilibili.com/opus/1236581050888486921)。
- 【推断】“小白龙”可作视觉简称；闭眼形象不等于原作设定“永不睁眼”，更不等于闭眼就能保证程序正确。[三视图](https://www.bilibili.com/opus/1238613841710940181)。

## 性格

- 【推断】目前实读的两篇 Codex 原帖没有给出完整人格、技能强弱、年龄、身世或对用户的称呼。原作文字设定较薄，应保留这条信息边界。[三视图](https://www.bilibili.com/opus/1238613841710940181)；[合集](https://www.bilibili.com/opus/1236581050888486921)。
- 【推断】【本项目新写】采用困倦、惜字、遇到异常会清醒一点的节奏；“可靠”体现在承认没看清、等待输出、准确交代停在哪一步，而非宣称闭眼秒修或后台无所不能。[延伸起点：三视图](https://www.bilibili.com/opus/1238613841710940181)。
- 【推断】【本项目新写】她对搭档亲近但不幼化；不照搬大肥鱼的“捏～”“店长”，也不替 GPT 龙娘承担全族的高傲或护短性格。[同组身份依据](https://www.bilibili.com/opus/1236581050888486921)。

## 口癖与常用句

- 【推断】未核实到可作为 Codex 本人原声引用的固定口癖。“刚刚睡醒就4000粉丝了？”是作者的动态标题，不能拿来证明 Codex 说过自己刚醒。[合集原文](https://www.bilibili.com/opus/1236581050888486921)。
- 【推断】【本项目新写】称用户“搭档”：既服务编程协作，也避免把睡衣小龙写成服侍型女仆。未找到原作称呼，不能标成作者设定。[设计参考](https://www.bilibili.com/opus/1238613841710940181)。
- 【推断】【本项目新写】“唔……便签给我，枕头先放旁边。”、“困归困，这里不能凭感觉。”、“这一轮先到这儿，便签还你。”均为项目原创；`>_` 只作为便签图案的文字借用，不暗示实际终端权限。[便签视觉来源](https://www.bilibili.com/opus/1238613841710940181)。

## 本项目怎么用（台词设计取向）

- 【推断】【本项目新写】保留便签、困意、拖鞋的视觉线索；低频使用“唔”“呼啊”，避免每句堆满省略号和动作。三到四句短句之间穿插清醒的工程判断。[设计起点](https://www.bilibili.com/opus/1238613841710940181)。
- 【推断】【本项目新写】`tool_start` 只说“准备读、准备改、要跑”；`tool_end:bash` 只确认返回，`turn_done` 只交还本轮结果，不说测试全绿。`permission_resolved` 同时兼容允许和拒绝；`steer_acked` 只说明读到补充，不说修改已经完成。[表演参考](https://www.bilibili.com/opus/1238613841710940181)；事件边界以项目 `src/shared/stage-events.ts` 为准。
- 【推断】【本项目新写】角色包里的完整对白均为本项目新写，没有宣称任何一句来自 Codex 原作口述。人格不绑定实际模型能力，不声称角色在用户不可见时继续执行。[身份锚点](https://www.bilibili.com/opus/1238613841710940181)。
