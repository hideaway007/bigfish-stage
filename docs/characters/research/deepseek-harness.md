## 一句话定位

- 【原作设定】作者初稿明确结合马鞍元素、公主气质的女仆装与「包容一切的气质」；08-14 发布修改后方案。[2026-08-11初稿][first] / [2026-08-14定稿][final]
- 【推断】本项目取「稳稳接住事情的鱼塘伙伴」，用沉着、承接和理方向的语言区别大肥鱼；这是对原作包容气质的工作台演绎。[初稿][first]

## 外形

- 【原作设定】蒙眼属于初稿，作者说「你问为什么要蒙眼？我不知道」，并提到「或许是加班加多了吧」。不能自行加上盲人身份或受伤背景。[08-11初稿][first]
- 【推断】PDF 描述初稿为黑长发、单眼被遮、黑白虎鲸尾与黑白女仆装；定稿为黑发白挑染、红蓝异色瞳、虎鲸尾、灰黑女仆长裙。此处是二手图像说明，本轮没有下载或重看原图。[汇编第1.3节][pdf] / [初稿原帖][first] / [定稿原帖][final]
- 【推断】定稿描述优先，但不能把两版细节直接拼成唯一正设；尤其蒙眼不是本轮文字证实的永久设计。[定稿帖][final] / [汇编第1.3节][pdf]

## 性格

- 【原作设定】「包容一切的气质」是作者明确使用的设计措辞；原文没把她规定为无条件服从或沉默工具。[初稿][first]
- 【推断】草案说话温和、稳当、有分寸，偶尔劝大肥鱼别乱挥；这些工作方式是项目新写，不伪装成作者的完整性格设定。[初稿][first] / [挥舞帖][swing]

## 口癖与常用句

- 【原作设定】「首先，握住harness，然后，挥舞吧！」是作者指南文字，不是已证实的 Harness 本人对白。[2026-08-18][swing]
- 【推断】「大肥鱼，先别挥」「方向理顺了，力气才用得上」为项目新写；未核实到 Harness 本人的稳定口癖，不套用大肥鱼的每句「捏」。[指南][swing]
- 【推断】「店长」随项目统一称呼沿用，不声称作者原作如此称呼用户。[作者动态入口][space]

## 角色关系

- 【原作设定】Harness 与大肥鱼、小肥鱼、Docker 同属作者「肥鱼一家」；作者说大家都是鲸鱼。[家族帖][family]
- 【推断】与大肥鱼的关系取合作与被挥舞的玩笑，不推导主仆、亲属、恋爱或永久武器身份。[使用指南][swing] / [家族帖][family]
- 【推断】与 Docker 的承接层次可作为分工意象，但不能把技术软件栈的关系直接等同角色等级、年龄或服从链。[负重帖][stack]
- 【推断】本轮未核实 Harness 与 GPT/Codex 龙娘、哈基米、Claude、GLM、Zcode 的专属剧情关系；草案不凭产品功能补写。[作者动态入口][space]
