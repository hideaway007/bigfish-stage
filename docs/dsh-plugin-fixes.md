## 实际使用证据

使用 DSH `0.2.2-rc.1`，单独的 `DSH_HOME`、浏览器会话与临时 Git 项目。没有改动日常 DSH 的模型配置。

- 按 README 从 GitHub 安装原始插件成功，随后在同一隔离环境加载本轮构建后的本地插件。这里分别验证了 GitHub 安装路线和修改后插件的运行，不把本地构建冒充已发布版本。
- 模型目录实际返回 GPT 与 Gemini；四位角色设置都显示这两个配置，修改未上场角色的模型没有改变正在使用的 GPT 会话。
- 工作文件夹切换成功创建 `project` 工作区。GPT 实际调用读文件工具，读取该目录中的 `hello.txt`，返回 `PROJECT_READ_OK Plugin verification fixture.`。
- 换手接力实际调用 `remote-magpie/antigravity/gemini-4-carbon`，返回 `RELAY_OK Plugin verification fixture.`。切回大肥鱼后，原来的 GPT 会话和回答恢复。
- 显示速度保存为 85 字/秒，进入新会话后仍为 85，宿主偏好文件同步保存。
- Git 抽屉识别测试文件改动，单文件撤回成功；另一处测试改动通过界面提交成功，测试仓库提交 `230c767`，随后显示无待提交改动。
- 原生 `/compact` 已实际成功执行；修改后的界面回放该会话显示用量而不捏造上限。真实摘要文本块、未识别命令的失败状态由针对性测试覆盖。

GPT 调用使用 `remote-magpie/codex/gpt-6.1-sol`。上述都是短任务；不代表所有模型、所有操作系统或长时间任务已经穷尽验证。
