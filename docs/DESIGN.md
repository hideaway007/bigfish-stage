# P5 Agent Stage — 产品与架构设计文档

## 1. 背景：为什么要颠覆现有 AI 聊天界面？

目前市面上的 AI 编程与对话界面（如 Codex、ChatGPT、常规 WebUI）千篇一律都是**“左侧会话列表 + 右侧垂直大聊天框”**的办公软件布局：
- **毫无交互感**：只能机械地打字、等滚动条、看日志，没有情绪价值与临场感。
- **同质化严重**：把最顶级的 Agent（Opus 5.5、Gemini 4）塞进一模一样的灰色气泡里，抹杀了不同模型鲜明的性格特征。

本项目直接对标 **《女神异闻录 5》(P5 / P5X)** 的殿堂级 UI 设计，将本地正在运行的 AI 任务包装成一场**怪盗团作战演出**。

## 2. 界面布局规范（严格对齐参考图三蓝框）

参考 `docs/p5-layout-reference.webp` 中的标注区域，整屏采用 **16:9 全屏锁定无滚动舞台（Viewport-locked Stage）**，背景为黑灰几何斜纹 + 高饱和猩红（`#E60012`）斜切色块 + 波普网点（Halftone Dots）：

|  +-------------------+     +---------------------------------------+  |

### 2.1 左蓝框：角色情报与状态卡（Left Character Card）
- **不规则红黑斜切多边形（`clip-path: polygon(...)`）**。
- **核心信息映射**：
  - `JOKER` 大字位 → Agent 代号（`OPUS 5.5` / `GEMINI 4`）
  - 黑底胶囊副标题 → 当前绑定的本地任务名 / 分支名（如 `雨宫莲·星舞` → `欧普斯·深夜重构`）
  - `★★★★★` → 当前算力 / Effort 等级指示器
  - `人格面具 / 属性 / 定位` → 模型内核、擅长领域、当前扮演的工程职责
  - 双胶囊徽章（原 CV 位） → `本地进程：运行中` + `口癖演出：开启`
  - 底部黑红双环圆形头像 → 点击或滚轮切换当前驻场 Agent（Opus 5.5 ⇄ Gemini 4 ⇄ Codex）

### 2.2 上蓝框：Agent 台词与动态对话框（Top Dialogue Box）
- 位于角色立绘左上方/正上方，采用 P5 经典**锯齿白边黑底漫画气泡框**。
- 当本地 Agent 正在思考、调用工具或输出结论时：
  - 自动提炼核心进度并叠加角色专属**口癖（Catchphrase）**。
  - 点击气泡可展开查看完整代码 Diff 或终端详细输出抽屉（不破坏主舞台美感）。

### 2.3 中央主舞台：可触摸、多表情立绘 / 3D 角色（Interactive Character Stage）
- **多层贴图差分（Sprite Layers）或 3D 渲染**：
  - 至少包含 6 种状态贴图：`idle`（待机耍帅）、`thinking`（扶眼镜/托腮思考）、`coding`（高速连击特效）、`smug`（一行秒杀 Bug 后的得意）、`shocked`（报错/测试挂掉时的颜艺）、`touch_react`（被玩家戳中时的傲娇/互动反应）。
- **触摸热区（Touch Hitboxes）**：
  - **头部/发梢**：触发特殊表情与吐槽语音/台词。
  - **眼镜/配饰/耳机**：触发帅气切镜（Cut-in）特写。
  - **身体/手部**：触发击掌（High-five）或催促干活反馈。

### 2.4 右下蓝框：玩家聊天与战术输入区（Bottom-Right Command Input）
- 沿着画面右下方的猩红斜切带排布。
- 支持直接输入自然语言对话，或点击 P5 风格斜切快捷键（`[ALL-OUT ATTACK 全力进攻/执行]`、`[ANALYZE 深度排查]`、`[BATON PASS 换手给 Gemini 4]`）。

## 3. 本地会话桥接架构（Local Session Bridge）

1. **数据源适配**：
   - **Claude Code Adapter**：监听本地 `~/.claude/projects/` 会话 JSONL 流或通过 SDK/CLI 管道通信。
   - **Codex / Gemini Adapter**：监听本地运行进程的标准输出与会话状态。
2. **状态映射器（State → Emotion Engine）**：
   - `session.thinking` → 角色切 `thinking` 贴图 + 顶部气泡冒省略号动效
   - `session.tool_call (Bash/Edit)` → 角色切 `coding` 贴图 + 背景斜切线加速流动
   - `session.tool_error` → 角色切 `shocked` 贴图 + 屏幕震动反馈
   - `session.turn_complete` → 角色切 `smug` 贴图 + 播报带口癖的总结台词
