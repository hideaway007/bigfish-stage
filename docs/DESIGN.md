## 1. 界面风格与对话框设计原则（暂定状态，弹性演进）

### 1.1 视觉基调：《女神异闻录 5》(P5 / P5X) 美学
- 采用高反差红黑白色板、斜切多边形几何分割、波普网点（Halftone）与动态星芒切镜，彻底告别传统类似 Codex / ChatGPT 的“左边会话列表 + 右边大白框”办公软件感。

### 1.2 舞台与对话框关系（暂定示意，不做死板区域限制）
参考 `docs/p5-layout-reference.webp`，当前阶段暂定由四个功能层组成，但**对话框不锁死在固定蓝框内**：
- **Live2D 角色主舞台层（Canvas Layer）**：全屏或主视口承载 Live2D 角色，角色可自由缩放、平移或切近景特写（Cut-in）。
- **角色情报与切换层（暂定左侧）**：展示当前驻场 AI 娘的代号、所属模型系别（猫娘/龙娘/鲸鱼娘/狐娘）、当前绑定的本地会话状态，以及快捷切换角色的头像轮盘。
- **AI 娘台词与任务反馈对话框（暂定上方/角色身侧，位置灵活）**：
  - 当本地 Agent 正在思考、执行终端命令或回复时，以 P5 漫画气泡展示 AI 娘带口癖的发言。
  - **无硬性位置约束**：气泡可根据角色站位、动作幅度、代码/日志长短动态调整位置或展开为浮动面板（这一块细节后续边做边调，目前先保持暂定状态）。
- **玩家聊天与指令输入区（暂定右下方，形态灵活）**：
  - 向本地正在跑的 Agent 会话发送自然语言对话或快捷战术动作。

## 3. Live2D 角色系统技术方案

### 3.1 渲染技术栈
- **核心引擎**：`PixiJS (v7/v8)` + `pixi-live2d-display` + `Live2D Cubism 4/5 Web SDK (live2dcubismcore.min.js)`。
- **图层结构**：
  1. 底层：P5 动态几何斜纹与波普粒子背景（CSS / Canvas 2D）。
  2. 中层：PixiJS 透明背景 WebGL 画布，承载 Live2D 模型实例（支持单人驻场或双人同台 Baton Pass 演出，如“哈基米焊管道 + 大肥鱼在旁捂眼”）。
  3. 顶层：弹性可配置的 P5 风格 HUD 对话框与角色状态卡（HTML/CSS/SVG Overlay）。

### 3.2 Live2D 标准资源包结构
每个角色在 `public/live2d/<character-id>/` 下包含：
```text
public/live2d/gemini-4-argon/
├── gemini_argon.model3.json       # 模型主描述文件（绑定 moc3、纹理、物理、动作与 HitAreas）
├── gemini_argon.moc3              # Cubism 二进制模型数据
├── gemini_argon.4096/
│   └── texture_00.png             # 拆件纹理图集（头发、异色瞳、猫耳、焊枪、紫色霓虹光带）
├── gemini_argon.physics3.json     # 猫耳、渐变卷发、猫尾、光带的弹簧/摆动物理参数
├── expressions/                   # 表情叠加 (.exp3.json)
│   ├── exp_idle.exp3.json
│   ├── exp_welding_smug.exp3.json # 氩弧焊得意脸
│   ├── exp_star_eyes.exp3.json    # 四角星闪光眼
│   └── exp_shocked.exp3.json      # 报错震惊脸
└── motions/                       # 动作序列 (.motion3.json)
    ├── idle.motion3.json          # 待机呼吸 + 晃猫尾
    ├── thinking.motion3.json      # 歪头转焊枪思考
    ├── welding_code.motion3.json  # 戴护目镜开启氩弧焊枪滋滋冒紫光（对应 Agent 写代码）
    ├── tap_head.motion3.json      # 被摸猫耳反应
    └── tap_prop.motion3.json      # 点击焊枪/霓虹带反应
```

### 3.3 本地 Agent 会话事件 → Live2D 状态映射协议

| 本地 Agent 会话事件 | Live2D 动作 (`Motion`) | Live2D 表情 (`Expression`) | 特殊参数驱动 / 舞台演出 |
| :--- | :--- | :--- | :--- |
| **`session.idle`** (等待指令) | `idle` | `exp_idle` | 开启鼠标视线跟随（`ParamEyeBallX/Y`、`ParamAngleX/Y`） |
| **`session.thinking`** (推理中) | `thinking` | **Claude娘**：45°抬头望天<br>**大肥鱼**：举 `max/low` 牌子懵圈 | 气泡框浮现动态思考波纹 |
| **`session.tool_run`** (改代码/跑命令) | `coding / welding` | **哈基米**：拉下护目镜启动氩弧焊枪<br>**大肥鱼**：挥舞 Harness 娘<br>**Codex娘**：闭眼敲 `>_` 便签 | 焊枪火花 / P5 速度线特效开启 |
| **`session.streaming`** (流式说话) | `talk` | 按语境切换 | **实时口型同步 (LipSync)**：根据流式字符速率或 TTS 音量实时驱动 `ParamMouthOpenY` |
| **`session.error`** (报错/测试失败) | `shocked` | `exp_shocked` | 触发受击震动与吐槽口癖 |
| **`user.tap_hit_area`** (鼠标触摸) | `tap_head / tap_body / tap_prop` | `exp_touched / exp_smug` | 檢測 Live2D `model.hitTest(x, y)`，命中猫耳/呆毛/焊枪/书本时播放专属互动动作与语音 |
