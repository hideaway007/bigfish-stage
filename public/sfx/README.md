# 舞台音效 (`public/sfx/`)

前端 `src/stage/sfx.ts` 播放舞台交互音效。默认全部使用 WebAudio 合成音（无需任何音频文件）。
B 侧想换成正式音频时，把文件放进本目录，并在 `manifest.json` 里登记即可，**不用改代码**。

## manifest.json 格式

```json
{
  "files": {
    "hover": "hover.mp3",
    "allow": "allow.mp3"
  }
}
```

- 键是音效名（见下表），值是本目录下的纯文件名（`mp3 / ogg / wav / m4a`，不能带路径）。
- 没登记的音效继续用合成音；登记了但文件缺失或解码失败，也会自动回退到合成音。
- 前端只在第一次播放时读取一次清单，改完需刷新页面。
- 浏览器策略：用户有过一次点击或按键之后才会发声；HUD 右上角 SFX 按钮可静音（保存在 localStorage `p5_stage_sfx_muted`）。

## 音效名

| 名称 | 触发时机 | 建议时长 | 听感 |
|---|---|---|---|
| `hover` | 鼠标划过审批选择肢 | 30–60 ms | 清脆轻巧的短滴声 |
| `select` | 审批选择肢高亮切换（键盘或鼠标） | 45–80 ms | 利落的游标切换音 |
| `allow` | 确认「允许执行」 | 120–220 ms | 明亮上扬的双音 |
| `deny` | 确认「拒绝执行」 | 120–220 ms | 低沉克制的下行双音 |
| `switch` | 左侧队伍切换角色 | 90–180 ms | 柔和清透的气泡短音 |

## 制作建议

- 44.1 / 48 kHz，128–192 kbps，单文件 ≤ 64 KB，首尾裁掉静音。
- 峰值约 -6 dBFS，避免压过其他声音。
- 只放自己制作或有明确授权的音频，仓库是公开的。
